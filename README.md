# API de Consulta de Capitais
 
## Descrição
 
Projeto desenvolvido para a disciplina de Desenvolvimento Back-end.
 
A aplicação consiste em uma API REST que permite consultar a capital de qualquer estado brasileiro ou do Distrito Federal por meio de sua sigla (UF).
 
## Tecnologias utilizadas
 
- Node.js
- TypeScript
- Express
